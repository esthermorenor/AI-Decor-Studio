# AI-Decor-Studio-

A personal approach ensures that every detail of each project is thoughtfully considered and beautifully executed. The result is a collection of refined interiors, ranging in scale and style—from traditional country residences to contemporary urban homes, as well as luxury hotels, spas, and beach villas.

## Ejecutar app local

Tienes dos formas:

```bash
./run_app.sh
```

o

```bash
python3 app.py --host 127.0.0.1 --port 4173
```

Luego abre en tu navegador:

- <http://127.0.0.1:4173>

### Cambiar host/puerto

```bash
./run_app.sh 0.0.0.0 8080
```

### Verificación rápida

```bash
python3 app.py --check
```
